Go by the last letter of the dictionary form — the Vardininkas. The stress can jump: mokinys → mokinio.

Plural — one ending for everything Kilmininkas daugiskaita

-ųusually
-iųafter a
soft stem

Go through the genitive singular: ends in -io, -iaus, -ės → -ių · anything else → -ų.

vaikas → vaiko → vaikų
kava → kavos → kavų
brolis → brolio → brolių
gėlė → gėlės → gėlių
alus → alaus → alų
žuvis → žuvies → žuvų

Masculine -is can also give -ies

dantis → danties (tooth) · vagis → vagies (thief). Rare — the main route stays -io.

t, d → č, dž before -ių

katė → kačių · medis → medžių · svečias → svečio.

Learn these as they come

moteris → moters · duktė → dukters · sesuo → sesers · vanduo → vandens · akmuo → akmens · šuo → šuns.

Watch out for po

po darbo — after work, genitive. po stalu — under the table, instrumental.

Self-check. Possession? Negation? Quantity? Wanting or seeking? A preposition? — one yes is enough
